# N2LN-QEM

Noise-to-Less-Noise Quantum Error Mitigation via Self‑Supervised Distribution Learning.

## Project Structure
- `config/` – Hydra configuration files
- `src/` – Source code (data, models, losses, training, evaluation, utils)
- `experiments/` – Experiment scripts and result reports
- `tests/` – Unit tests
- `notebooks/` – Analysis and visualisation notebooks
